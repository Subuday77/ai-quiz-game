# AI Quiz Game — расходуемые звёзды и магазин плюшек

**Статус:** согласованные требования, 3 ноября 2026.  
**Исходная ветка:** `feature/quiz-fact-dedup-tags`.  
**Ветка реализации:** `feature/star-perks-shop`.  
**Принцип:** сервер — единственный источник истины для баланса, наград, ходов, допустимых категорий и решений о подсказках.

## 1. Экономика звёзд

- Звёзды **расходуемые**: при покупке подсказки или обмене потраченные единицы исчезают из текущего баланса. История заработанных звёзд/достижений хранится отдельно и не уменьшается при расходовании.
- Двусторонний обмен **без комиссии**: `10 bronze ⇄ 1 silver`; `10 silver ⇄ 1 gold` (`100 bronze ⇄ 1 gold` через серебро). Нельзя создать дробные звёзды; операция атомарная.
- **Platinum** нельзя покупать, получать обменом или обменивать на другие звёзды. Пока платина **только копится**. Привилегия «без рекламы» и косметика сейчас **не реализуются**; старые идеи не считаются согласованной функциональностью.
- Награды в партии: при **5, 10, 15 правильных ответах** на основные вопросы — bronze, silver, gold соответственно; каждый порог выдаётся **ровно один раз**. При правильном ответе на бонусный Q16 — platinum. Платину дают именно за правильный ответ, не за сам факт появления Q16.
- В игре 15 основных **слотов** (сложности 0–14); следующий слот не обязан равняться числу правильных ответов. После пропуска номер/сложность продвигаются, а счётчик правильных — нет. Пропуск хотя бы одного слота исключает награду за 15 правильных в данной партии.

## 2. Бронза — удаление неправильных вариантов

| Действие | Цена | Лимит |
| --- | ---: | --- |
| Убрать один неверный ответ | 2 bronze | Максимум два удалённых ответа на вопрос |
| Убрать **сразу два** неверных ответа | 3 bronze | Только когда ещё не удаляли варианты |
| Убрать один, затем ещё один | 2 + 2 = 4 bronze | После первого «убрать сразу два» недоступно |

- Генератор один раз проставляет каждому варианту **правдоподобность** по шкале 0–100: насколько этот ответ похож на правильный, **не вероятность того, что он фактически верен**.
- Правильный ответ всегда получает **100** (принудительно в серверной логике). Остальным вариантам — оценка генератора. Эти оценки **не проверяют повторно** критик, Terra или другие модели; никаких дополнительных AI-вызовов.
- Убирают только варианты, явно **не равные ключу правильного ответа**, начиная с минимального балла. При равенстве оценок выбор **случаен с равными шансами**. Выбранные для скрытия варианты **фиксируются** на сервере в состоянии текущего вопроса, чтобы перезагрузка не меняла результат.
- Клиент получает только разрешённые к отображению варианты; правильный ключ и оценки остаются приватными. Отсутствующие/устаревшие оценки не должны препятствовать показу уже проверенных вопросов — нужна явно задокументированная политика совместимости.
- В магазине подсказок две кнопки и общий индикатор **«Удалено 0/2», «1/2», «2/2»**. Недоступные действия неактивны. Успешное удаление — игровая подсказка и закрывает доступ к Q16.

## 3. Серебро — управление категориями

| Действие | Цена | Ограничение |
| --- | ---: | --- |
| Случайно сменить категорию текущего вопроса | 1 silver | Общий лимит **2 смены/вопрос** |
| Выбрать новую категорию из списка | 2 silver | **1 ручной выбор/вопрос**, в рамках тех же 2 смен |
| Исключить категорию **до начала партии** | 5 silver **за каждую** | После исключения должно остаться **не меньше 16** категорий |

Для обеих смен в процессе игры:
- сложность/номер слота не изменяются, новая категория отличается от предыдущих категорий в **текущем слоте**;
- отвергнутая категория **не запрещается на последующие слоты**;
- после 2 успешных смен обе кнопки выключены, после одной ручной — ручная выключена;
- показывать общий индикатор **«Смены 0/2»** и отдельный для выбора **«Выбор 0/1»**, со сбросом на новом вопросе;
- если новая категория/вопрос не получились, звёзды **не списываются**, счётчик не увеличивается; повторный запрос не должен удваивать платёж;
- смена категории — игровая помощь: лишает бонусного Q16.

**Предыгровое исключение:** до первого вопроса можно отметить категории, увидеть общую цену, подтвердить оплату и применить исключения только к **данной игре**. Выбор действует и для главных вопросов, и для бонуса. При **ровно 16 оставленных категориях** обе платные смены категорий в процессе игры **отключаются на всю партию**. Если категорий больше, система не должна позволить платной смене исчерпать запас, необходимый для оставшихся уникальных категорий в рамках одной проходки.

**Два списка категорий:**
1. `allowed_categories` — неизменяемый после старта список из справочника **минус оплаченные исключения**;
2. `available_categories` — текущий расходуемый пул для выбора категорий.

Когда доступный пул исчерпан (в том числе при автоматических повторах генерации), он восстанавливается **только из `allowed_categories`**, **никогда** из глобального списка. Это действует также для fallback из общего банка подтверждённых вопросов и для Q16. Автоматическая смена из-за ошибок генерации **бесплатна**, **не расходует 2 смены** и **не считается подсказкой**. Не надо лишать игрока возможности продолжить партию из-за временного сбоя генератора.

> Не уточнено отдельным решением: исключение категорий *до старта* считается ли «игровой подсказкой» для допуска к Q16. До явного решения не менять текущую бонусную политику незаметно; выбрать и зафиксировать правило перед включением платной операции.

## 4. Золото — пропустить вопрос

- **1 gold = пропуск одного текущего основного вопроса**, без ответа и без зачёта правильного.
- Слот/сложность игры увеличиваются на 1. `correct_main_answers` не увеличивается; пороги наград проверяются **только по правильным ответам**.
- Пример: 8 правильных, Q9 пропущен, Q10 правильный → 9 правильных, Q11 правильный → 10 правильных и серебро. Золото за 15 правильных после любого пропуска в 15 слотах уже недостижимо.
- Пропуск считается помощью и **блокирует Q16**. Уже полученные звёзды сохраняются.
- **Категория пропущенного вопроса возвращается в доступный пул**: другой вопрос по той же теме может выпасть позднее. **Тот же вопрос** снова не показывается в рамках пользовательской истории (обычная защита от повторов сохраняется).
- Пропуск Q16 не предлагается: на бонусе игровые подсказки недоступны.

## 5. Жалобы и платина — только будущие функции

**Жалобы:** пока в интерфейсе **неактивная заглушка «Скоро появится»**. Без счётчика, списаний и AI-вызовов. Согласованные будущие правила: **5 бесплатных жалоб за день на игрока**, далее **1 bronze за дополнительную**, максимум одна жалоба от игрока на конкретный вопрос, жалоба не является подсказкой, технические баг-репорты бесплатны. Позднее — отдельный AI-агент для разбора/арбитража жалоб и предложений компенсации звёздами, а **сервер** контролирует начисления, лимиты и аудит.

**Платина:** игрок получает звезду за правильный Q16, но пока **не может тратить её**. Предложения «7 дней без рекламы» и эксклюзивная косметика отложены, не являются активными товарами магазина. Реклама, кошелёк, биллинг, донаты вне текущей задачи.

## 6. Границы транзакций и безопасность

- Для каждой операции проверять сервером: авторизацию, принадлежность игры игроку, фазу, номер вопроса, доступный остаток, лимит подсказок, отсутствие гонки и корректный переход состояния.
- Списание звёзд **атомарно с результатом** (скрытые варианты, новая тема, пропуск или исключение). Ошибка генерации или конфликт — без списания и без увеличения счётчика.
- Повторный POST/ретрай запроса не должен повторно списывать баланс или применять эффект. Нужны idempotency key/ключ операции, блокировка соответствующих строк и проверка уже применённого действия.
- История баланса — журнал: `award`, `spend`, `exchange_in`, `exchange_out`; баланс не может быть отрицательным. Разделять достижения «заработано» и остатки «можно потратить».
- Правильный ответ не отправляется в API выдачи вопроса; оценки правдоподобности приватны. Ни одна подсказка не может скрыть правильный вариант.
- Совместимость со старыми вопросами и перезапуском backend обязательна. Контракты PostgreSQL и Angular изменяются согласованно; миграция Alembic нужна для новых полей/состояний.

## 7. Проверки при реализации

- Курсы обмена в обе стороны, нехватка баланса, конкурентные вызовы и двойное списание.
- Удаление самого дешёвого, два сразу за 3, два по очереди за 4, тай-брейк при равных оценках, запрет удаления правильного, reload/retry.
- Случайная/ручная смена в любой разрешённой последовательности, общий 2/2 и ручной 1/1, неуспех без списания, истощение категорий, минимум 16 после предыгровых исключений.
- Циклический сброс пула **только** к списку игрока, бесплатная автоматическая ротация при ошибках AI, fallback общих утверждённых вопросов в рамках фильтра.
- Пропуск на Q9 → серебро на Q11, нет золота после пропуска, повторное использование категории, нет Q16, нет пропуска в бонусе.
- При обычной идеальной партии сохранились 15 правильных → золото → Q16 → платина. Жалобы только disabled placeholder.
- Offline Python tests + Angular tests/build. Живую PostgreSQL/браузерную проверку и реальные платные вызовы AI отмечать отдельно; не считать их прошедшими без исполнения.
